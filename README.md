# Focus Desk

A Pomodoro timer with a built-in task list. Plain HTML, CSS and JavaScript — no build step, no dependencies.

## Features
- 25 / 5 / 15 minute focus, short break and long break modes
- Task list with completed-session counts per task
- Saves tasks and daily session count in your browser (`localStorage`)
- Sound alert, live countdown in the tab title, dark mode, keyboard support (Space starts/pauses)

## Run locally
Open `index.html` in a browser. That's it.

## Deploy on GitHub Pages
1. Push this folder to a new GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
